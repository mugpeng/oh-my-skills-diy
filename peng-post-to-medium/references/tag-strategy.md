# Medium Tag Strategy

Medium allows up to 3 tags per post. Choose wisely — they directly affect discoverability.

## Rules

- Max 3 tags per post
- Max 25 characters per tag
- Case-insensitive (Medium normalizes)
- No special characters except hyphens

## Popular Programming Tags

| Category | Tags |
|----------|------|
| Languages | `python`, `javascript`, `typescript`, `rust`, `go`, `java` |
| Web | `web-development`, `react`, `nodejs`, `frontend`, `backend` |
| Data | `machine-learning`, `data-science`, `ai`, `deep-learning` |
| DevOps | `devops`, `docker`, `kubernetes`, `aws`, `cloud` |
| General | `programming`, `software-engineering`, `tech`, `coding`, `tutorial` |

## Strategy

1. **First tag**: Broad, high-traffic (e.g., `programming`, `javascript`)
2. **Second tag**: Specific to your topic (e.g., `rust-cli`, `react-hooks`)
3. **Third tag**: Audience or format (e.g., `tutorial`, `beginners`, `productivity`)

## Don'ts

- Don't use tags that are too generic alone (e.g., `tech`)
- Don't repeat the same concept (e.g., `javascript` + `js`)
- Don't use tags with very few followers
- Don't exceed 25 characters per tag
